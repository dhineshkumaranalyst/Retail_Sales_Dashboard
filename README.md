# Retail_Sales_Dashboard
An interactive E-Commerce Sales Analysis Dashboard built using Microsoft Excel to analyze sales performance, order trends, product performance, and customer insights.

Business Questions Answered:
1.What is the Total Sales generated?
2.What is the Total Profit?
3.What is the Total Number of Orders?
4.What is the Total Quantity Sold?
5.What is the Average Order Value (AOV)?
6.Which products generate the highest sales?
7.Which products generate the highest profit?
8.Which category performs best in terms of sales?
9.Which category generates the highest profit?
10.What are the monthly sales and profit trends?

Key Features:
 Interactive sales performance analysis
 Total orders and quantity sold analysis
 KPI-based sales monitoring
 Product performance analysis
 Customer and sales trend analysis
 Interactive Slicers and filters
 Pivot Tables and Pivot Charts
 User-friendly and visually engaging dashboard
